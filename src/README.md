# src

This directory contains the main source code for the project. Below is a brief description of each subfolder:

- `baselines/`
  Contains implementations of baseline algorithms and methods for comparison in experiments (e.g., betweenness, degree, dice, etc.).

- `community_detection/`
  Includes core algorithms and utilities for community detection, as well as extra algorithms and similarity functions.

- `conf/`
  Configuration files (YAML) for experiments, dataset analysis, hyperparameter search, and other settings using HYDRA.

- `graph_environment/`
  Code related to the environment and framework for running experiments on graphs.

- `methods/`
  Main methods and advanced algorithms, including deep reinforcement learning agents and custom approaches (e.g., DRL-agent, nabla_cmh).

- `utils/`
  Utility scripts for experiment management, impact analysis, statistics, and other supporting functions.
